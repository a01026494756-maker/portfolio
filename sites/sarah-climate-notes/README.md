
## 콘텐츠 수정

`content.mjs`에서 이름·좌우명·프로젝트 정보를 수정한 후 `npm run build`를 실행합니다. 결과는 `dist/`입니다. 이미지 경로는 배포할 수 있는 URL 또는 `dist` 내 정적 경로를 사용합니다. 로컬 이미지를 사용할 경우 `build.mjs`에 해당 파일 복사 처리를 추가하세요. `null`인 역할·AI 정보는 ‘미정’, 대표 이미지는 준비 중 상태로 표시합니다. 프로젝트 공식 이름을 확정하면 `title`과 `officialTitle`을 함께 채우세요.

카드 본문과 공개 링크는 분리했습니다. 상세는 같은 탭, 공개 사이트는 새 탭으로 열립니다. 홈 목록에서 상세로 이동한 경우 목록 복귀·브라우저 뒤로가기 시 카드 위치와 포커스를 복원합니다. 연락처가 없어 연락 메뉴는 표시하지 않습니다.

첫 화면의 리본 배경은 `assets/hero-ribbon-background-v1.png`입니다. 사용자 참고 캡처의 텍스트·UI를 imagegen으로 제거하고 가려진 부분을 재구성한 이미지입니다. 홈의 `hero-stage` 전체 너비·높이를 채우는 배경이며, 글과 버튼은 그 위에 표시합니다. 모바일도 별도의 하단 이미지 영역 없이 전체 배경을 유지합니다. ‘배움이 만든 것들’부터는 단색 배경이며 상세·오류 화면도 단색입니다. 어두운 오버레이·그라데이션·이미지 필터는 사용하지 않습니다. 기존 SVG 리본은 중복 표시하지 않습니다. Google Fonts가 차단되면 시스템 한글 글꼴로 표시합니다.

사이트의 접근 범위는 Sites 설정을 따릅니다. 새 사이트는 소유자 전용이며, 수업 동료에게 공개하려면 공유 범위를 변경해야 합니다. 연결된 외부 프로젝트의 공개 접근·하드웨어 동작은 별도 검수가 필요합니다.
